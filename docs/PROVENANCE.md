## 解釈を明示した計算規則

1. 堕天のHP割合は、倍率適用前の内部生命割合で判定します。現在値と最大値へ同じHP倍率を適用。
   倍率切替だけで内部HPが回復しない構造です。致死耐性時は最終表示でHP1へ調整します。
2. 深淵の6%は基礎値を基準に毎ターン線形加算し、95%で止まります。
   HPは減少後の最大HPへクランプし、最大HP減少だけで0にはなりません。
3. 断罪は「2段階を蓄積して、次の命中で発動」のルールです。発動後0に戻ります。
4. 連羽は0.7倍の独立2ヒット。各命中だけで断罪翼の蓄積が進みます。
5. 敵先攻とプレイヤー先攻はラウンドにつき各1行動。速度差は先攻と回避率に反映。
   極端な速度倍率を行動回数無限増加へ変換せず、999/1000の値は保持します。
6. CTとバフは発動ターン終了時にも1減少。CT4は1・5・9ターン目に使用可能。
7. 致命傷判定は敵の一攻撃につき一度。複数耐性を一度に消費しません。
8. 特殊な終末判定は第三形態9ラウンド目。速度・通常行動停止で時計を止めません。
