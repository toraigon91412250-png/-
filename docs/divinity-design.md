# 失われた神格 — 全面再構築
基準: Sites version 34 / 2252d7c21a448e6aa9633ca28faeae5fb0167344。公開は行わない。

## 成長の道筋
- 新規ゲームは権能なし。斬撃・防御から開始。第1階クリアで黒翼試練。
- 黒翼を奪還すると残る4試練を同時解放。同じ基準難度で取得順を固定しない。
- 試練は固有条件→戦闘中覚醒→新しい技を使って封印を破る→勝利で正式解放。敗北は一時覚醒を持ち帰れない。
- 各権能Lv.1 基本技、Lv.2 蓄積の強化、Lv.3 二方向の分岐（無料で戦闘外変更）、Lv.4 連携強化、Lv.5 奥義。既存倍率を保ち追加戦術を与える。
- 神格1: 黒翼奪還 / 防御後の反撃。神格2: 第5階+2権能 / 系統連携。神格3: 第10階+3権能 / 状態浄化。神格4: 第15階+全5権能 / 一戦一度の再起。神格5: 第20階+全権能Lv.5+封印の真相試練 / 真・神格解放。
- 第5段階は全権能を一時統合する専用コマンド、専用技。神格5向け「無窮の神座」で予告攻撃・複数封印・権能切替・防御反撃を要求する。
- 共鳴はLv.5権能2種の組み合わせを記憶する。新ルートでは元の権能を消費しない。既存2装備枠と倍率は保持。

## 戦闘の規則
- 黒翼: 防御2回で覚醒。羽を溜め、翼嵐で消費。烈翼は火力、羽衣は回復と防御を選ぶ。
- 深淵: 予告された侵食波を防御し、直後に攻撃して覚醒。還蝕は侵食を追加し、敵から受けるダメージを3ターン30%軽減する。本編・鏡像戦にも適用。
- 堕天: 試しの一撃は致死にならずHP45%へ。次の低HP時の攻撃で覚醒。既存の背水倍率を維持し、誓約で自分から低HPに入れる。
- 断罪: 異なる攻撃2種の後、防御で覚醒。専用の証2つを消費して防御を貫く。既存の断罪蓄積とは別に扱う。
- 堕天王: 予告重撃を防ぎ、直後に攻撃して覚醒。受け流しは敵が先に行動する場合も障壁を先に展開する。致死耐性は戦闘中の権能切替で補充されない。
- 各試練は覚醒前45%、覚醒技使用前10%のHP封印を持つ。通常ダメージ・侵食とも封印を飛ばせない。高火力で封印に到達しても、命中した攻撃は儀式の判定に数える。
- 神格2から「呼び戻す」で装備2枠目を1行動かけて変更する。神格5は4行動だけ全5権能を追加し、終了時に元の組み合わせへ戻る。
- 封印の真相: 重撃への防御と3系統の専用技が必要。無窮の神座: 防御と異系統の技を組み合わせ、封印を1枚ずつ計3枚破る。両試練は36行動で決着が必要。
- 新技のCTは既存技と独立。ゲージ不要の専用奥義は既存の超堕天撃ゲージを消費しない。
- 本編第2〜5階は敵HP4倍、第6〜20階は2.5倍、敵攻撃は第2階以降1.55倍。既存権能の強さを保ち、新技・防御を使う余地を作る。旧ルールのテスト用データにはこの補正を適用しない。

## 世界観
自らの意思で封印した。権能を奪還するたび断片が戻る。全能の力が人々の選択を奪ってしまう未来を止めるため、自分で封印した。真の覚醒は支配の再開でなく、他者の選択を守るために力を選び直すこと。
