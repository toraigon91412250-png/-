# いれーな REBORN | audit6 戦闘UI改修レポート

作成日：2026-10-23（JST）
基準：ユーザー提出 `irena-source 3.zip`（audit5・20階層本編版）
改修範囲：通常いれーな戦闘の見た目と、進行中の戦闘でのナビゲーション表示。Solのバランス調査は未反映。

## 改修

- 承認済みモックに合わせ、カイザー画像を上段、いれーな画像を下段へ変更。双方のHPバーと画像を分離。
- 既存の20階層版にある透過カイザー素材を再利用（素材画像は無変更）。
- モバイル戦闘画面では、ホーム・強化・ガチャ等の共通ナビゲーションを非表示（戦闘終了時には復帰）。撤退操作を維持。
- 戦闘コマンドを2列へ整理。防御を右下、超堕天撃を横長の最下段へ。内部のコマンド配列や戦闘計算は変更せず、CSSの表示順だけで実現。
- アイコンは既存のSVGを使用し、装飾・メダリオン枠・背景グラデーションで視認性と特別感を調整。新しい画像生成素材は本編に取り込んでいない。
- 権能状態欄を「権能・自分の状態」と明記。敵の侵食・HPは敵側に表示。既存のゲージ、CT、技の使用可否とログを維持。
- 「戦場へ」「技を選ぶ」で既存のスクロール移動機能を維持。実機1画面内で全体を収める設計ではなく、技ボタンへのジャンプを提供。

## コード差分

ソース変更：`web/src/components/App.js`、`web/src/components/game.css`。
監査の整合維持：`tests/audit-baseline.js` に旧audit5復元層追加、`tests/combat-ui-audit6.test.js` と `reports/combat-ui-audit6/authorized-changes.json` を追加。
これ以外の既存ソース／画像／戦闘ロジック／セーブ仕様を変更していないことを元ZIPとの全ファイル比較で確認。

## 実施済み検証

- `npm test` : 320 / 320 合格
- `npm run check` : 44 JSファイル構文チェック成功
- `npm run build` : HTML構築成功、画像43件埋込
- Chromiumで単体HTML（インラインHTML表示）を実行。320×700、375×812、390×844、430×932、768×1024、1024×768の6画面で横はみ出し0、敵・自分の並び、防御・必殺の並び、ナビ非表示を確認。
- Chromiumで通常戦闘開始、斬撃によるTURN 1→TURN 2進行、撤退ダイアログ、撤退後のナビ復帰を確認。ブラウザのアドレス制限のため、ローカルStorage模擬を使った画面検証。実機Safari保存挙動の確認ではない。
- 旧版の内容を保持したSHA-256差分監査を更新して再検証。既存テストの削除・弱体化なし。
