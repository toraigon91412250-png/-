# 失われた神格・対面整理型 UI

公開版 v37 (29d5df7) を基準に戦闘の表示のみを改修。自分と敵のHP・状態を分離し、敵の予告、蓄積ゲージ、大きなコマンドを配置。画面高に応じて2または4技を表示し、全技にページ切替でアクセス可能。黒紺と金の背景を新規生成し WebP 40,740 bytes に最適化。人物画像は既存素材を使用。戦闘計算・報酬・セーブ仕様は変更なし。

自動テスト575件成功、ビルド成功。詳細なブラウザ結果は同フォルダのJSON参照。実機iPhoneは未検証。ユーザー指示に従い追加テストは停止。

真・神格解放時の長い装備名による横はみ出しは幅制限で修正。既存の斬撃、カットイン、ヒットストップ、振動、大ダメージ数字を保持。履歴検証の旧スナップショットは変更せず、今回の差分のみ新しい厳密ハッシュ層として記録。
