# いれーな REBORN — audit5 / 20階層本編

## 実装内容

実験場の20階層ルートを本編の通常攻略に採用。敵20種の名前・数値・テンポ補正、黒晶殻・重圧・再生、防御のHP12%回復・重圧解除・斬撃/権能への蓄勢3倍（3ターン）、報酬・育成ペースを移植しました。羽弾最終5倍、権能/刻印の性能は変更していません。

本編ホームの冒険ボタン・戦闘待機画面から進行し、自動保存・JSONバックアップ・実績に反映します。実験場の重複する20階層入口は削除。既存の三相決戦・崩鎧試練などの独立試験は残しています。試作モジュールはルール共有と過去の回帰テストのためソースに保持しています。

通常編の権能入手は5/10/15階で堕天/堕天王/断罪。8/12/16階で羽撃ち分け/星墜/不屈。購入済み権能はレベルを下げず欠片8個へ変換。移行前に旧対応階層の権能報酬を取得済みなら、その報酬は新階層で再付与しません。

P報酬は90+階層×12、各権能欠片は8+floor(階層/5)×2。初回勝利の基礎Lvは最低1+階層×3（既存の高レベルは下げない）。再戦もPと欠片を入手できます。

## 解放順序

通常20階層突破 →「？？？？？」→ ワープ → EX/ステラ同時解放 → ステラ勝利で専用いれーな。

実験場版のステラ→EXという強制順序やEX縮小数値は採用していません。EX/ステラ/専用いれーなは元の戦闘数値・報酬・フラグを使用。EX初回100P、通常編完了時50ステータスPの一回制限も維持。

共鳴・レイドは新10階層（旧50階相当）で解放。旧解放済みの履歴も有効。通常階層に関わる実績6件は旧10/30/50/70/90/100から新2/6/10/14/18/20へ対応し、名称・総数36件・既達成/受取済み履歴は維持します。

## 旧セーブ移行

- 旧到達階層F → min(20, floor((F-1)/5)+1)。旧51階は新11階。
- 旧5階分すべての撃破履歴がある場合、新1階分をクリア済みに換算。旧100階クリア済み/後続コンテンツ解放済みなら全20階クリアとして保持。
- 所持P・SP・育成・装備・素材・実績・報酬受取・解放状況は保持。移行そのものでP/SP/欠片を配りません。
- 旧通常編完了は50SP受取済みとして記録。旧EX撃破済みはEX初回100P受取済みとして記録し、曖昧な欠損フラグからの再付与を避けます。
- 後続コンテンツのクリア記録がある場合、その前提解放を復元して再ロックを防止します。
- route20:1 と legacyCleared を保存し、再読込/JSON再取込で再変換しません。
- 新形式はversion5。同じ保存キー irena-reborn-v3 を使用。旧audit4は新形式をエラーとして保護するため、知らない形式を黙って100階層として上書きしません。旧v1/v2/v3/v4データは新アプリから取り込めます。
- 初回自動移行前の元JSONを別キー irena-reborn-before-main20 に一度だけそのまま退避。JSONインポートでは既存の上書き確認を維持。
- 旧ルールの進行中戦闘は、新ルールへ途中から変換せず新しい拠点へ戻します。元戦闘のJSONは自動移行前バックアップに残ります。所持品・育成・攻略の永続データは保持します。
- 新ルールの刻印戦闘チェックポイントは、蓄勢・鎧・回数・乱数消費を合法な行動履歴から復元します。従来どおり、チェックポイント対象の刻印を装備した通常いれーな戦闘が対象です。
