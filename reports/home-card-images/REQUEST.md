# いれーな REBORN：ホームカード画像組み込み指示書

## 目的
添付したユーザー承認済みの画像4枚を、現在開発中の最新版ゲームのホーム画面にある該当カードへ組み込む。
**現在進行中の「冒険を続ける／戦闘に戻る」バグ修正を先に完了し、その成果を維持すること。**

## 画像対応
- `images/01_blackwing_summon.jpg` → 「黒翼召喚」
- `images/02_engraving_equipment.jpg` → 「刻印・装備」
- `images/03_abyss_raid.jpg` → 「深淵レイド」
- `images/04_upgrade_equipment.jpg` → 「強化・装備」

上記の画像はユーザーが指定した実物。代わりの生成画像・検索画像は使用しない。
1枚目の女性は召喚カードの演出用であり、「いれーな本人」として扱わないこと。

## 必須作業
1. Codex作業環境にある**最新の修正済みソース**を確認し、未完了の変更や差分を把握する。古いソースZIPで上書きしない。
2. ホームカードの現在の実装、CSS、画像参照方式、レスポンシブ対応を調査する。
3. 4枚を対応カードに表示する。カード名、既存のリンク、解放条件、データ表示、ボタン操作は維持する。
4. スマホ縦画面を優先し、画像のトリミング・暗幕・文字コントラストを調整。文字やボタンが絵に埋もれないこと。
5. 既存アセット運用方式に沿って配置し、不要な重複・巨大化・別画像への置換を避ける。
6. 関連テスト・構文チェック・ビルドを実行。可能ならスマホ相当の画面サイズで表示とタップを検証する。
7. 変更したファイル、確認結果、残る未確認事項を報告し、動作確認用HTMLと最新ソースZIPを出力する。

## 厳守
- 今回の**必須スコープはホームカード4枚の画像組み込みのみ**。
- 戦闘ロジック、敵のステータス、セーブ互換性、解放順序、ゲームバランスを変更しない。
- 敵の攻撃予告・行動予測など、新しい戦闘仕様を追加しない。
- 無関係なファイル変更、リファクタリング、機能追加はしない。
- テストの削除・緩和や、失敗の隠蔽はしない。
- 現在のバグ修正との競合があれば、勝手に解決を決めず差分と原因を明示する。
