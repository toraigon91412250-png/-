# ホームカード画像4枚の組み込み

## 対象

直前の修正版ソース（irena-home-resume-fix/irena-source.zip、SHA256 4dc38c7c694bca06f47812b99f5a405fea1c269b84a2eede68824a21bc1d9da0）と作業環境のコードが一致することを確認してから変更しました。添付指示書はREQUEST.mdに保存しています。

指定された4枚をassets/home-uiへ原本のまま1回ずつ追加し、対応するホームカードの背景へ組み込みました。

| 原本 | カード |
|---|---|
| 01_blackwing_summon.jpg | 黒翼召喚 |
| 02_engraving_equipment.jpg | 刻印・装備 |
| 03_abyss_raid.jpg | 深淵レイド |
| 04_upgrade_equipment.jpg | 強化・装備 |

召喚画像の女性はカードの演出用で、主人公の立ち絵・カットイン・名前付きキャラクター画像に流用していません。既存のいれーな/ステラ/EXの画像指定は維持しています。

## 表示と操作

以前のCSS紋章の代わりに指定背景を配置し、文字の背面には暗幕を重ねました。画像の縦横比はobject-fit:coverで維持します。召喚と刻印は右側の主題を優先。強化画像には原本から白い上下余白があるため、画像ファイルを加工せずCSSで表示範囲を調整しています。召喚/刻印の画像に含まれる矢印と既存の矢印が二重にならないよう、該当カードの追加グリフだけを非表示にしています。カード全体のボタンと既存リンクはそのままです。

新しい背景は既存のステラ/EX立ち絵カードとは別の表示クラスを使い、既存2枚のレイアウトを変えません。元画像は再圧縮・再生成していません。画像4枚のSHA256と、配布HTMLに埋め込まれた画像のSHA256が対応していることをブラウザで確認済みです。

## 変更範囲と保持した修正

既存ファイルの編集はweb/src/components/App.jsとweb/src/components/game.cssの2件のみです。他に指定アセット4枚と今回の検証記録を追加しました。既存のtools/testsは変更していません。

「冒険を続ける／戦闘に戻る」の分岐は直前納品とバイト一致し、ブラウザでも再検証しました。途中の戦闘へ戻ったときのHP・ターン・ゲージ・保存JSONを維持します。戦闘、敵能力、セーブ形式、解放条件、報酬、ゲームバランスは変更していません。戦闘予告や予測は追加していません。
