# audit12 — 左から右へ流れる戦闘カットイン
2026-10-24（日本時間）。audit11を別ディレクトリへ複製し、承認済みv2設計を実装。

## 変更
- 通常いれーなの羽弾・穿羽・連羽・超堕天撃に、新規キャラ画像を使う横流しカットインを実装。画面外−110%→−3%→＋3%→＋115%。顔の減速区間を設け、右へ加速して退場。
- 羽弾860ms/命中650ms、穿羽920ms/700ms、連羽900ms/600・760ms、破壊680ms/300ms（解除240ms）、必殺1600ms/1200ms（解除1120ms）。戦闘ターン数やCTは変更せず、演出時間のみ変更。
- 羽根槍は戦場上の実際の敵画像位置を参照。命中輪・斬線・実ダメージ数値・HPを既存の事実列に同期。
- 連羽の弾は実際のhitイベント数から予約。1hit撃破で2発目を捏造しない。連羽の戦闘ロジックのバグ修正は対象外。
- 画像原本PNG2枚保持、ゲーム用WebP quality92を別ファイルで作成。既存素材削除なし。
- iPhone向け既存コマンド領域を維持。戦場内で完結し全画面モーダルなし。減光は局所的。音は既存音源・音OFF設定を継承し、新規音源は未制作。
- 画面離脱時の清掃、画像読込失敗時のフォールバック、二重操作防止はaudit11の仕組みを維持。
