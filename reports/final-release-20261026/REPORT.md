## 1. 鏡像戦の戦術

- 第三形態の封印は、準備した必殺、破鏡、防御後の反撃、蓄積後の攻撃系統切替、羽衣破壊後の羽系連携で解除できる。未準備の必殺だけでは無料の破砕・鏡裂を得られない。
- 1行動で解除する封印は最大1枚。3/2/1枚残存時は第三形態開始HPの70/40/10%を下限とし、残っている間は勝利できない。
- 終焉予兆を「敵行動2回後」「次の敵行動」に分けて表示。予兆中の必殺は術式を断絶し、敵応答・詠唱・神域バフを更新して鏡裂と破砕蓄積を得る。敵先手、CT、スタンにも対応した。
- 終焉を防御して生存すると破砕蓄積100%と鏡裂を得る。終焉の既存攻撃倍率やダメージ上限を下げず、正しい対処後に反撃できる。
- 成功した対処、破砕方法、鏡裂などを専用イベントとログで記録する。

主な実装：`web/src/utils/mirrorTrial.js` の `mirrorSeverRitual`（94行）、`mirrorBreakSeal`（104行）、`mirrorDamageGate`（112行）、`mirrorResponse`（126行）。関連試験：`tests/mirror-stage2.test.js`、`tests/mirror-finale.test.js`。

## 3. 育成と鏡像の難易度

- 通常の鏡像入場はLv.20以上。ボタン表示と開始処理で同じ判定を使用し、低レベルでの直接操作も拒否する。開発者モードの例外は維持。
- 存在しない `battle.level` を参照していた育成補正を `battle.build.level` へ修正。高育成にも低育成向けの補正が適用される不具合を解消。
- 鏡像の敵HP・攻防圧力を調整し、育成してから挑む戦闘にした。詳しい定数は `MIRROR_RULES` と開始時の育成補正を参照。
- 第一→第二形態の侵食持越しを最大35%に制限。20%など上限以下の蓄積は保持し、第三形態のリセットは維持。24構成の回帰試験で、95%侵食を引き継いで第二形態を羽弾一発で飛ばす再現条件を防いだ。あらゆる超火力構成での一撃を禁止する固定無敵ではない。

## 4. 状態表示と操作性

- 封印数、破砕蓄積、現在成立する次の一手、終焉予兆、鏡裂、適応中の攻撃系統を確認できるようにした。
- 詳細は折りたたみ式。常時表示を短くし、スマホ向け余白とキーボードフォーカスも調整。
- HP下限の基準を「第三形態開始時HP」と明記。鏡裂には防御倍率と「次の攻撃行動で消費・命中不要」を表示。
- 羽衣・神域・完全解放の効果を詳細に記載。内部名 `mirrorFullRelease` を「鏡界・完全解放」へ変更した。
- 破鏡の回復を実HP差分から「破鏡 回復＋N」と表示し、鏡裂解除も別の事実として表示。上限を超えた見かけの回復量を出さない。
- リザルトで行動数・破鏡・防御回数を振り返れる既存機能、形態別再挑戦・遺物、第三形態の全回復・ゲージ100%も維持。

## 7. 残存課題と引き継ぎ

- 高育成レイドは今回も全勝。HP／攻撃の一律増加案は耐久構成に敗北を偏らせたため採用していない。次回は敵の行動や対処機会から検討する。
- 鏡像では羽衣連携が高勝率で、侵食・防御固定方針は低め。勝ち筋は複数確認したが、全構成の最適解や完全な均衡は未証明。断罪弱体化を解決策にしない。
- すべての構成を7～14行動へ機械的に収めていない。短期決着と長期攻略が残る。
- 実iPhone／Safariの長時間動作・音、実プレイヤーの初見勝率は未確認。`file://` 直接実行は管理ブラウザの制限で未確認。
- 過去の第二段階レポートは当時の結果。育成レベル参照の修正前の勝率を現行値として使わない。最新値はこのディレクトリの再実行結果を参照する。
- 巨大なプレイ用単体HTMLは納品対象外。公開先は既存プレイ用Siteを使用し、audit4ダウンロード用Siteは変更しない。

次回は公開コミットを基準に作業し、`npm test`、`npm run check`、`npm run build` を実行する。変更時は封印ゲート、1行動1枚、各破砕ルート、終焉の行動順、保存・再挑戦、旧セーブ移行、報酬不変、320px表示を確認する。追加のバランス比較では実イベントを集計し、独立条件とシードと実戦数を明記する。
