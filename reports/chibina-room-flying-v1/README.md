# ちびーなルーム飛行試作 v1

## 起動

1. このZIPを展開し、プロジェクトのルートで `npm install` を実行します。
2. `npm run build` で単体HTMLを生成します。
3. 生成された `irena-play.html` をブラウザで開きます。

`irena-play-chibina-room-flying-v1.html` は今回のビルド済み単体HTMLとして、ソースZIPと別に配布します。

## ルームの開き方

初回はタイトル画面の「再誕の物語を始める」を押してホームへ進み、ホームの「ちびーなルーム」画像カードを選びます。

- キャラをタップすると選択できます。
- 下部の「この子をホームに設定」でホーム表示を保存します。
- 吹き出しの「次へ」を1回押すと台詞が1行進みます。最後まで自動で閉じません。
- 「ホーム」でルームを閉じます。
- 全イベントの個別再生は、開発者画面の「ちびーな会話の個別再生」から行います。

初回の入室ではCR-095が優先再生されます。再生済み状態はゲーム本体のセーブと別のローカルストレージキーに保存します。

## 実装範囲

正式採用JSONの220イベントをそのまま読み込みます。黒翼は公式v6の奥翼・手前翼・本体のWebPを使い、CSS transformで3回の羽ばたきから滑空へ移ります。残り4人は既存の公式WebP静止画をゆっくり浮遊させます。

`EVENT_COVERAGE.csv` にIDごとの台詞確認と自然発生条件の扱いを記載しました。自然文の発生提案・動作提案は完全なルール式ではないため、一般イベントは近接・休息・直前行動・移動・孤立のヒューリスティックで扱います。CR-095、CR-201、CR-274には個別条件があります。

公開、デプロイ、mainへのマージは行っていません。
