# 通常いれーな戦闘UI改修

## 正本・対象

作業環境の最新コードを使用しました。着手前にホームカード4画像版ソースZIP（SHA256 75c2c7411d0bde70e3242a9d6722376166d8947f7ee7fbca3d118a269da23d89）とweb/assets/tools/testsが一致することを確認しています。添付の軽量ZIPは指示書と参考JPEGのみで、ゲームソースを上書きしていません。参考JPEGをゲーム素材として貼り付ける実装も行っていません。

今回の表示対象は通常いれーなを使う通常/EX/レイド/神域/実験場の共通戦闘画面です。最終決戦用いれーなとステラの画面構成は維持しています。三相決戦の追加修正版に関する以前からの未回収事項もそのままで、今回戦闘ルールを修正した版ではありません。

## 変更内容と理由

| 項目 | 変更内容 | 理由 |
|---|---|---|
| 戦場 | プレイヤーを手前左、敵を奥右に配置。敵HPは右上、プレイヤーHPは手前下に整理 | 参考図の対戦構図を現存する立ち絵で表現し、HPの所属を読み取りやすくする |
| HP | プレイヤー側を緑の単色へ | 敵の赤紫と区別し、派手なグラデーションを抑える |
| ヘッダー | スマホの通常いれーな戦闘だけ108pxから52pxへ。戦闘に不要な所持通貨・英字見出しを表示しない | 戦場と操作へ画面を使う。通貨・素材の確認はホーム等で従来どおり可能 |
| 重要情報 | 現在の権能・バフ/状態、断罪蓄積、耐性回数、形態、EX終末タイマーは常時表示 | 操作に必要な現在情報を隠さない。攻撃/行動/ダメージ予測は追加しない |
| 詳細 | 能力値と全ログを開閉式にし、直近の実ログを1行表示 | 情報を失わず、毎ターンの過密さを減らす |
| 技 | 名前13〜14px、説明12px。押下領域44px以上 | 元の説明10pxより読みやすくする。技は従来と同じイベントに接続 |
| 補助メニュー | 通常いれーなの戦闘内では重複するフッターを表示しない | ホーム等の実験場/開発者/ガイド入口は維持。戦闘中の主導線は下部ナビと既存ジャンプボタン |

通常いれーなの画面にだけstandard-combat/standard-shellを付け、CSSをその中へ限定しています。新しいアニメーション・装飾・画像は増やしていません。既存の斬撃・被弾・ダメージ表示・カットイン・スキップ・入力ロックは維持しました。

## 羽弾・穿羽・連羽の仕様

コマンド生成は実際の装備刻印 `b.marks.includes('split')` に従います。所持しているだけでは切り替わりません。

- 羽撃ち分け未装備：斬撃、黒翼・羽弾、破壊の権能、超堕天撃、防御。
- 羽撃ち分け装備：斬撃、穿羽、連羽、破壊の権能、超堕天撃、防御。羽弾は表示しません。
- 行動不能中は従来どおり復帰コマンド。最終決戦の「使えない技を非表示」「説明を非表示」も維持。

表示するコマンド構成だけを変え、戦闘エンジンの技ID/性能/APIは互換性のため維持しています。羽弾基礎1.95、穿羽の羽弾比1.3、連羽0.7×2、黒翼の最終5倍、交互使用の1.15補正は変更なし。ゲージは各39、CTは羽弾2/穿羽3/連羽2で、発動ターン末の従来減算も変更していません。羽弾を隠すため、刻印装備時にプレイヤーが選べる羽系の技は2種類になります。これは依頼された表示変更による選択肢の差であり、倍率を再調整したものではありません。

## 防御

通常の防御ボタンは「被ダメージ70%軽減 / ゲージ＋18」としました。実際の軽減はそのターンの敵攻撃に適用され、通常は防御を選ぶたびに行う必要があります。防御値そのものの永続上昇や完全無敵ではありません。先攻/後攻に関係なく防御フラグが渡される既存処理を維持し、ゲージ上限や最低1ダメージの扱いも変更していません。

三相決戦の防御だけは既存の試作追加効果があるため、その説明は「軽減70%・ゲージ＋18・HP12%回復」としています。重圧解除・蓄勢の実処理や、その戦闘のルールも変更していません。

## 保護と変更ファイル

ゲーム本体はApp.jsとgame.cssを編集。READMEに最新版案内を追記しました。既存のエンジン・進行・保存・設定・全アセットは着手時ハッシュと完全一致（protection.json、protected-baseline.json）。保存形式、報酬、解放順、成長、権能分類は変更なし。ホームカード4画像と「戦闘に戻る」修正を維持し、継続戦闘のHP/ターン/ゲージ/保存JSONも確認しました。

テストは4件追加し、既存のホーム限定保護テストを今回許可された戦闘表示にも対応させました。その他の関数・保存ハンドラの保護は維持し、エンジン全体の一致と新コマンドの排他表示を別テストで検証しています。三相決戦ブラウザテストは、旧7コマンド期待値を指定の6コマンドへ変更し、隠した羽弾を押す操作を実際に表示される連羽/穿羽へ置き換えました。戦闘テストの削除、倍率/報酬/保存のアサーション緩和はしていません。差分はsource.diff、変更一覧はchanged-files.jsonに記録しました。

- 三相決戦の表示変更後の試遊103項目も成功（この記録だけは最終の防御文言明確化前です）。最終ビルドで戦闘復帰の5項目も再実行。98件検証でも戦闘復帰、EX、刻印操作を確認しています。

実行：npm test、npm run check、npm run build、node reports/battle-ui/browser-check.mjs chromium、同webkit（この環境ではPLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1）、既存tools/browser-e2e.mjs・ui-regression.mjs・three-phase-browser.mjs、戦闘復帰チェック。HTTPの4181が最新版、4182が変更前の復元ビルドです。ログ・結果JSONを同梱しています。

## 配布・未確認事項

ソースZIPと単体HTMLを出力しました。ZIPを別フォルダに展開して全174テスト・構文28ファイル・ビルドを再実行し成功、再生成HTMLは配布版とバイト一致しました（recovery.json）。スクリーンショットはbefore-390.jpgと各ブラウザの390-normal.jpg/390-split.jpg、短い画面で技へ移動した390-commands-viewport.jpg等です。固定ナビを含む全ページ画像では、撮影位置のナビが途中の技欄に重なって見えるため、技へ移動したビューポート画像も併用します。

iPhone Safari実機、数時間の連続操作は未確認。file://起動は管理ブラウザで遮断されており成功とは報告しません。外部公開、GitHub操作、デプロイはしていません。現在の敵画像は白背景付き原本で、参考図のような完全に背景へ溶け込む表示には素材上の限界があります。顔や衣装を生成し直したり、参考画像から切り抜いたりしていません。
