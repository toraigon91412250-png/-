# いれーな REBORN — 失われた神格 再構築版

公開version 34のGitコミット `2252d7c21a448e6aa9633ca28faeae5fb0167344` を基準とした開発版です。ChatGPT Sitesへの公開更新は行っていません。

## 遊び方

1. 新規開始は斬撃と防御のみ。通常第1階を突破すると、ホームの「神格と権能を取り戻す」から黒翼の試練へ進めます。
2. 試練の条件は戦闘画面に表示します。黒翼は防御2回で覚醒し、その戦闘中から翼嵐を使えます。勝利して初めて正式に持ち帰れます。
3. 黒翼後は深淵・堕天・断罪・堕天王を好きな順番で奪還できます。失敗・撤退でも既に獲得した権能や育成は失いません。
4. 権能Lv.1〜5は欠片で個別育成。Lv.3で二方向の成長分岐を選び、戦闘外で無料変更できます。Lv.5で専用奥義、共鳴への接続が開きます。
5. 神格段階は別の成長軸です。黒翼→本編5階＋2権能→10階＋3権能→15階＋全5権能と進みます。
6. 本編20階・神格4・全5権能Lv.5で「封印の真相」へ。突破後に神格5へ覚醒し、「真・神格解放」「万象・帰還」と高難度「無窮の神座」が開きます。

神格は自らの意思で封印したものです。奪還と覚醒のたびに記憶が戻り、最後に封印した理由を知ります。

## 変更内容

- 購入中心の権能獲得を、固有試練・戦闘中覚醒・勝利による奪還へ変更。
- 羽の蓄積、侵食の逆用、低HPの誓約、断罪の証、防御反撃を追加。既存の堕天・断罪の倍率は維持。
- 神格の固有能力として、防御後の反撃、異系統連携と戦闘中切替、浄化、一度だけの再起、全権能統合を実装。
- 共鳴10種を組み合わせとして利用可能にし、元のLv.5権能を消費しない方式へ変更。既存の共鳴効果・装備2枠は保持。
- 20階の本編進行、従来の鏡像戦・EXカイザー・レイド・最終決戦・神域連戦を継続利用。
- スマートフォンの戦闘画面を改修。6コマンドずつの切替、敵の予告、自分と敵の状態、神格段階を表示。覚醒演出は通常1.5秒、動きを減らす設定で0.4秒、ボタンで即時終了できます。
- 開発者ツールに段階0〜5の独立試験データ、神格段階だけ／権能Lvだけを変更する操作を追加。

## 素材

提供された5枚をすべて利用し、原本を `assets/divinity/originals/` に保存しました。配信用WebPは別ファイルです。対応は以下です。

|神格|添付順|外見|
|---|---|---|
|1 神性の微光|3枚目|白い衣装、翼がまだ顕現していない姿|
|2 神翼の胎動|5枚目|黒白の翼、細い光輪|
|3 神威の顕現|2枚目|広がる翼と光の神域|
|4 神域の再臨|4枚目|冠と強い光、拡大した翼|
|5 真・神格解放|1枚目|日蝕・赤い球・巨大な翼|

封印中の段階0は段階1の絵を抑えた彩度で表示します。新規生成・描き直しは行っていません。5枚の顔・髪・瞳の一貫性と、目立つ手指・人体の破綻がないことを目視確認しています。

## セーブ

- 従来の本編保存キーを維持します。初回移行時に元JSONを `irena-before-divinity-v1` へ一度だけ保存します。
- 育成、所持金、素材、共鳴、装備、既存神格段階を保持。従来の共鳴合成で消費した素材権能はLv.5で復元します。
- 古い進行中戦闘は出発前に戻し、移行通知に明示します。新ルールの本編・通常ボス戦は新技・装備切替・真の神格を含めて再開できます。
- 奪還試練の一時覚醒はセーブしません。再読込時は挑戦前からやり直せます。
- 未対応の神格データ、壊れたJSON、移行前バックアップの保存失敗はエラー表示し、自動で新規データに置き換えません。
- JSON読込時は確認画面を出し、読み込んだ元ファイルを日時付きキーでも保持します。端末の保存領域が利用できない場合はJSON書き出しを利用してください。

## 起動・再検証

Node.js 22以上とPython 3を推奨します。

```sh
npm ci
npm test
npm run check
npm run build
python3 -m http.server 8765 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8765/` を開きます。`dist/` は配信用、`irena-play.html` は画像内包の単体版です。iPhoneではHTTP経由の配信を利用してください。ファイルアプリのプレビューはゲーム実行環境ではありません。

```sh
node tools/divinity-simulation.mjs
node tools/divinity-adventure.mjs
node tools/divinity-browser.mjs
DIVINITY_BROWSER=webkit node tools/divinity-browser.mjs
```

ブラウザテストにはChromiumとPlaywrightのWebKitが必要です。Chromiumの既定パスは `/usr/bin/chromium`。WebKitの独自実行パスは `DIVINITY_WEBKIT_PATH` で指定できます。検証環境では不足ライブラリを作業用ディレクトリへ展開して起動しました。これらの環境用ライブラリはゲーム配信物に不要です。

元プロジェクトの画像照合テストは、ソースフォルダと同じ親フォルダに `assets-to-integrate/`、`combat-ui-user-input/`、`supplied-raid/` を参照します。納品する完全ソースZIPにはこの構成を含めます。

検証結果は `reports/divinity-rebuild/`、仕様は `docs/divinity-design.md` を参照してください。過去の固定ハッシュ検査には、元リポジトリの方式に沿って今回の変更前後を記録しています。既存の動作テストは削除せず、新ルールの回帰テストを追加しています。

## 検証範囲の限界

ChromiumとLinux版WebKitで実操作・描画・保存を検証しています。実機のiPhone Safariや、プレイヤーによる長期の遊び込み評価は未実施です。WebKitの合格を実機Safariの完全な保証とは扱いません。

この版は公開前の開発成果物です。元の復元フォルダと公開版の履歴付きチェックアウトは維持し、変更は別作業ブランチ `feature/divinity-rebuild` に保存します。
